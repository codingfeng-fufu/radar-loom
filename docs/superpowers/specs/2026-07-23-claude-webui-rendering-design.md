# Claude WebUI 渲染统一设计

## 目标

统一一体化操作台右侧 Claude 区域的视觉和交互表现，覆盖对话页、历史会话页、加载态、错误态、工具调用、权限确认和危险模式提示。设计基线采用 C 方向：安静的阅读体验、明确的工具状态、可见的知识库上下文。

## 范围

包含：

- Claude 顶部栏、消息线程和输入区；
- Markdown、代码块、表格、引用和数学公式的显示；
- 工具调用的折叠摘要、展开详情、运行状态和错误状态；
- 当前工作目录、当前页面和图谱上下文提示；
- 历史会话列表、空状态、加载状态和接口错误状态；
- normal、accept edits、plan、危险模式等权限状态的视觉区分；
- 桌面和移动端布局。

不包含：

- Claude 调用协议、会话 JSONL 格式和模型配置；
- 知识库 Viewer、图谱和左侧文件工作区；
- 会话数据迁移或删除。

## 视觉系统

- 页面底色使用浅灰绿工作区色，内容区不使用大面积渐变；
- 顶部栏、输入区和工具详情使用白色表面与细边框；
- Claude 回复采用无气泡阅读排版；用户消息使用轻量背景块区分；
- 绿色仅表示当前关联、成功、可执行链接和运行状态；
- 普通状态、成功、运行中、警告、失败分别使用稳定的颜色和图标语义；
- 圆角保持在 6-8px，避免卡片套卡片；
- 内容宽度限制在适合阅读的范围，代码块允许横向滚动。

## 组件行为

### 消息线程

Claude 回复支持标题、段落、列表、表格、引用、链接、代码块和数学公式。消息内容使用安全 Markdown 渲染，代码块保留语言标识和复制操作。长回答不改变布局宽度。

### 工具调用

工具调用默认显示一行摘要，例如“已读取知识页 · 2”。点击后展开文件、命令、结果或错误详情。运行中、成功、失败和取消状态必须可区分；工具详情不能遮挡输入区。

### 知识库上下文

顶部或输入区附近显示当前工作目录。Viewer 页面、图谱节点和分类上下文以可关闭的上下文条进入对话；输入区状态行显示 `normal mode · 当前页已关联` 等当前状态。

### 历史会话

历史页沿用相同的顶部栏、底色、边框和排版。每条会话显示短 ID、开始时间、消息数和最后一条消息摘要。加载中、空历史、接口错误分别使用独立状态视图；点击整行进入会话。

### 权限和错误

权限确认和危险模式使用高对比警示区域，但不改变普通消息的布局。错误状态必须显示原因和可执行的返回/重试操作。加载状态显示阶段文字，避免长时间只有 spinner。

## 响应式约束

- 桌面端消息正文最大宽度约 760px；
- 移动端顶部栏、上下文条和输入区允许换行；
- 输入区固定在可视区域底部，消息线程独立滚动；
- 代码、表格和工具详情不得撑破视口；
- 保留草稿和滚动位置，不因状态切换重置。

## 实现边界

优先修改现有 WebUI 前端补丁及其测试；必要时增加安全 Markdown 渲染辅助。不得改变 Claude 请求协议、会话存储目录、知识库 API 或会话数据格式。现有危险模式和知识库上下文消息协议必须保持兼容。

## 验收标准

- 对话、历史、空状态、加载态和错误态视觉一致；
- Markdown、代码块、数学公式和工具详情在真实浏览器中正确显示；
- 工具调用可折叠/展开，权限状态清晰可辨；
- 当前页面和图谱上下文可见且可关闭；
- 桌面和移动端无重叠、溢出或输入区遮挡；
- 历史会话可以加载最近和旧会话；
- 现有 WebUI、知识库和图谱回归测试全部通过。
