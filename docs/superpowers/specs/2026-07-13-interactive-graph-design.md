# 技术雷达交互图谱工作台设计

## 目标与边界

新增独立全屏 `graph-view.html`，面向 100+ 节点、400+ 边的日常探索。工作台使用成熟的 Cytoscape.js 和 fCoSE 布局，不自行实现物理布局算法。保留现有 `graph*.md` Mermaid 文件作为可审计的文本产物；交互工作台是新增视图，不替换它们。

## 数据契约

`scripts/render_graph.py` 在现有 Mermaid 输出之外生成 `graph-data.json`：

- `generated`：生成日期。
- `stats`：节点、边、孤立和断链计数。
- `categories`：八个分类标签及固定颜色。
- `nodes`：`id`、`label`、`kind`、`tags`、`category`、`confidence`、`summary`、`degree`、`href`。
- `edges`：稳定 ID、`source`、`target`。

节点和边均按稳定键排序，JSON 使用 UTF-8 和确定性缩进。`kind` 为 `moc`、`project` 或 `concept`；主分类按 README 中的分类顺序取页面第一个匹配标签。`href` 统一指向 Viewer 页面。

## 工作台布局

顶部工具栏包含工作台名称、节点搜索、布局重排、适应视图、标签开关和移动端筛选按钮。左侧为无卡片嵌套的筛选栏：概览统计、分类复选框、项目复选框和“仅显示选中节点的一跳邻居”。中间 Cytoscape 画布全幅占据剩余空间。右侧详情栏显示节点类型、标签、信度、摘要、连接数、邻居清单和“在 Viewer 打开”。

窄屏下侧栏改为可开关抽屉，详情栏变成底部面板；画布始终保持稳定高度，不被动态内容挤压。

## 视觉与交互

- 节点颜色按八个分类编码；项目页为紫色菱形，MOC 为深色圆角矩形，概念页为圆形。
- 节点大小按度数分档，避免 EvidenceFirst 等核心节点无限放大。
- 默认只显示重要节点标签；开启“全部标签”后显示全部，搜索命中和选中节点始终显示。
- 单击节点：选中、显示详情并高亮一跳邻居；再次点空白取消。
- 搜索：按标题模糊匹配，选择结果后居中并聚焦。
- 分类和项目筛选可组合；无匹配时显示明确空状态。
- “一跳聚焦”只改变可见性，不改变底层数据；清除选择恢复当前筛选结果。
- 布局使用 fCoSE `quality: default`，固定随机种子不可用时以排序后的输入降低抖动；提供手动重排按钮。

## 安全与失败处理

所有详情内容通过 `textContent` 写入，不拼接来自 Markdown 的 HTML。JSON 加载失败或 Cytoscape/CDN 不可用时显示可读错误和 Mermaid 备用入口。工作台只读，文件路径由生成器产生，不接受任意查询路径。

## 验收

1. Python 测试验证 JSON 计数、稳定排序、节点字段、分类/项目/MOC 类型和边引用完整性。
2. 浏览器验证画布非空、节点与边数量、fCoSE 布局、搜索、分类筛选、一跳聚焦、详情和 Viewer 跳转。
3. 桌面 1440×900 与移动端 390×844 验证无布局重叠、画布尺寸稳定、抽屉/底部详情可用。
4. 验证 `graph*.md` 原有输出与健康检查不回归，两个服务仍仅监听 localhost。
