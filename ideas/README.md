# Idea Lab

独立记录灵感、实际尝试、阻塞点和组合关系。这里的内容不进入技术知识库索引、分类或主图谱。

## 常用命令

```bash
python3 ideas/scripts/new_idea.py "一句话 Idea" --problem "想解决的问题"
python3 ideas/scripts/build_idea_index.py
python3 ideas/scripts/render_idea_graph.py
python3 ideas/scripts/check_idea_health.py
```

正式页面位于 `ideas/pages/`，快速捕获位于 `ideas/inbox/`。机器生成的 `_index.md`、`data/idea-index.json`、`graph.md` 和 `data/idea-graph-data.json` 不手工编辑。
