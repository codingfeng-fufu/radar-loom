# 马尔可夫 Markov

## 核心内容

### 1. 马尔可夫性质与形式化

**马尔可夫性质(Markov Property)**:给定当前状态,未来与过去条件独立。形式化写法:

$$P(X_{t+1} \mid X_t, X_{t-1}, \dots, X_0) = P(X_{t+1} \mid X_t)$$

一句直觉:**当下就是充分统计量**——过去的信息全部压缩进了 $X_t$。这条假设看似苛刻,却是让"状态空间上的动力学"变得可计算的关键;失去它,任何未来预测都要背着整条历史轨迹。

**高阶马尔可夫**:$P(X_{t+1} \mid X_t, \dots, X_{t-k+1})$ 依赖最近 $k$ 步。但通过**状态扩展**技巧——令新状态 $Y_t = (X_t, X_{t-1}, \dots, X_{t-k+1})$——任意有限阶马尔可夫链都可以还原为一阶。所以"无记忆"不等于"弱表达力",代价只是状态空间指数膨胀。

### 2. 马尔可夫链(Markov Chain,状态可见)

**三要素**:状态空间 $S$、转移矩阵 $P_{ij} = P(X_{t+1}=j \mid X_t=i)$、初始分布 $\pi_0$。矩阵每行和为 1(随机矩阵)。$n$ 步转移即 $P^n$。

**状态分类**:
- **常返/瞬态(recurrent/transient)**:从状态 $i$ 出发几乎必然回到 $i$ 者为常返
- **周期性(period)**:$d(i) = \gcd\{n : P^n_{ii} > 0\}$;$d=1$ 称非周期
- **不可约(irreducible)**:任意两状态互通

**稳态分布(stationary distribution)** $\pi$ 满足 $\pi P = \pi$、$\sum_i \pi_i = 1$。

**遍历定理(Ergodic Theorem)**:有限状态、不可约、非周期的马氏链存在唯一稳态分布,且从任意初始分布出发 $\pi_0 P^n \to \pi$;时间平均等于空间平均。这是 MCMC 能工作的数学根基。

**细致平衡(detailed balance)** $\pi_i P_{ij} = \pi_j P_{ji}$ 蕴含稳态,但比稳态更强(要求链**可逆**)。Metropolis-Hastings 的接受概率就是为强行制造细致平衡而设计的。

**经典例子**:
- **PageRank**:网页有向图 + 阻尼跳转的转移矩阵,稳态分布 $\pi$ 就是网页重要性
- **随机游走**:图上的 $P_{ij} = 1/\deg(i)$,稳态分布 $\pi_i \propto \deg(i)$
- **赌徒破产 / Ehrenfest 模型 / 排队论 M/M/1**

### 3. 连续时间马尔可夫链(CTMC)

离散时间 $P$ 换成**生成矩阵(Q-matrix)** $Q$:非对角 $Q_{ij}\ge 0$ 是从 $i$ 跳到 $j$ 的速率,对角 $Q_{ii}=-\sum_{j\ne i}Q_{ij}$。转移概率 $P(t)=e^{Qt}$。**泊松过程**、**生灭过程**、化学反应网络都是 CTMC 的实例;稳态求 $\pi Q = 0$。

### 4. 隐马尔可夫模型 HMM(状态隐藏)

结构:隐状态 $Z_t$ 是一阶马氏链,观测 $X_t$ 仅依赖 $Z_t$。三个经典问题及其算法:

| 问题 | 算法 | 复杂度 |
|---|---|---|
| **评估** $P(X_{1:T})$ | 前向算法(Forward) | $O(T\cdot \|S\|^2)$ |
| **解码** $\arg\max_Z P(Z\mid X)$ | Viterbi | $O(T\cdot \|S\|^2)$ |
| **学习** $\arg\max_\theta P(X;\theta)$ | Baum-Welch(EM 特例) | 迭代 |

工程用途:语音识别(GMM-HMM 时代)、词性标注 POS、命名实体识别 NER、生信序列比对(Pfam / HMMER)。CRF 是它的判别式对偶——同样处理序列,但直接建模 $P(Z\mid X)$ 而非联合。

### 5. 马尔可夫决策过程 MDP(强化学习骨架)

五元组 $(S, A, P, R, \gamma)$:状态、动作、转移 $P(s'\mid s,a)$、奖励 $R(s,a)$、折扣 $\gamma\in[0,1)$。目标是找策略 $\pi(a\mid s)$ 最大化期望累计回报。

**Bellman 方程**:

$$V^\pi(s) = \sum_a \pi(a\mid s)\Big[R(s,a) + \gamma\sum_{s'}P(s'\mid s,a)V^\pi(s')\Big]$$

$$V^\ast(s) = \max_a\Big[R(s,a) + \gamma\sum_{s'}P(s'\mid s,a)V^\ast(s')\Big]$$

**解法家族**:
- 已知模型:值迭代 / 策略迭代(动态规划)
- 未知模型:蒙特卡洛、时序差分 TD、Q-learning、SARSA
- 大状态空间:函数逼近 → DQN / A2C / PPO / SAC(现代深度 RL)

**POMDP** 把状态改成隐变量(智能体只看观测),需要维护 belief state,通常比 MDP 难若干个数量级。LLM Agent 在真实环境中本质上做的就是 POMDP 决策。

### 6. 马尔可夫链蒙特卡洛 MCMC

**目标**:从难以直接采样的分布 $p(x)$(尤其是贝叶斯后验)中取样。**思路**:构造一条以 $p$ 为稳态的马氏链,跑够久就近似从 $p$ 采样。

- **Metropolis-Hastings**:提议分布 $q(x'\mid x)$ + 接受概率 $\alpha=\min\{1, \frac{p(x')q(x\mid x')}{p(x)q(x'\mid x)}\}$
- **Gibbs 采样**:依次从各分量的条件分布 $p(x_i \mid x_{-i})$ 采样;是 MH 的特例
- **Hamiltonian Monte Carlo (HMC) / NUTS**:借用哈密顿力学做长距离提议,高维下远优于随机游走;Stan、PyMC 的默认后端
- **诊断**:$\hat R$、有效样本数 ESS、trace plot;判断是否收敛与混合是否充分

MCMC 之外的替代:变分推断 VI(把采样换成优化)、Normalizing Flows、Diffusion Models(Diffusion 的正/反向过程本质就是马尔可夫链)。

### 7. 与 LLM 的关系(反例视角)

严格意义上 Transformer **不是**马尔可夫的:自注意力显式看整段上下文,$P(x_{t+1}\mid x_{1:t})$ 依赖全部前缀。但工程上:
- 上下文窗口截断 → 高阶马尔可夫近似
- KV Cache → 把"过去的注意力状态"压缩进当前"状态",思想上呼应扩展状态技巧
- 推测解码 / speculative decoding → 用一个小模型的"提议分布"加速大模型采样,和 MH 的思路同源

### 8. 常见误解与陷阱

1. "马尔可夫 = 无记忆 = 只能表达短依赖" ❌ —— 状态扩展可以吃掉任意有限阶
2. "只要能写出转移矩阵就有稳态" ❌ —— 需要不可约 + 非周期 + 正常返
3. "MCMC 跑得越久越准" ⚠️ —— 忽略 burn-in 与自相关会导致有效样本数远低于迭代数
4. "HMM 的 EM 一定收敛到全局最优" ❌ —— 只保证到局部最优,初始化敏感
5. 把马尔可夫性质当"物理定律"套用 ⚠️ —— 现实过程往往需要**先设计合适的状态**才近似满足马尔可夫性(状态设计是建模的核心工作,不是免费午餐)

## 和我的项目的关系

马尔可夫假设是理解 [[序列标注模型 HMM CRF]] 的前置知识,也是**理解 LLM 为何"不是马尔可夫的"** 的对照物——Transformer 显式看整段上下文,严格意义上违反马尔可夫性;但受限于上下文窗口 + KV Cache,工程上可以近似看成"高阶马尔可夫"或"截断记忆"。这一点对 [[EvidenceFirst]] 有直接启发:如果把 RAG 的检索-生成过程建模成 MDP(状态=当前证据集合,动作=下一步检索/生成),就可以借鉴强化学习的策略优化思路来做多跳检索的调度。另外,MCMC 的"细致平衡"思想可以启发 [[TripleChecker]] 中三元组一致性校验的迭代收敛过程——不是一次性打分,而是让判断在图上迭代直到稳态。
