# Agent 记忆架构

## 核心内容

Agent的记忆架构是Agent领域最核心的研究问题之一，通常分为三个层次：工作记忆（Working Memory）——Agent当前正在处理的信息，相当于人类的短期记忆，容量有限，通常就是LLM的上下文窗口；情景记忆（Episodic Memory）——Agent过去做过的事情的记录，通常用向量数据库存储，按相似度检索，相当于人类对具体事件的回忆；语义记忆（Semantic Memory）——结构化的知识图谱，存储实体和关系，相当于人类的长期知识。三个层次的记忆配合使用：工作记忆处理当前任务，情景记忆检索过去的类似经验，语义记忆提供结构化的知识支撑。

## 和我的项目的关系

知识图谱就是Agent的语义记忆——这是我的研究和Agent方向的核心交汇点。[[EvidenceFirst]]本质上就是给Agent的语义记忆加了可观测性层：大多数Agent系统用KG做语义记忆时，直接假设记忆里的知识都是对的，直接拿来用；EvidenceFirst在每次访问记忆时都做一次结构检查——「这条知识在记忆里是否真的存在？」、「从A到B的路径是否真的连通？」，并把检查结果作为置信度信号返回给Agent。这个思路可以直接延伸到Agent领域——Agent的记忆不应该是被动的存储，还应该是主动的质量监控器。这是一个很好的未来研究方向，面试时可以主动提。
