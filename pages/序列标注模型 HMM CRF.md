# 序列标注模型 HMM CRF

## 核心内容

HMM（隐马尔可夫模型）是生成式模型，对观测序列和隐藏状态序列的联合概率建模，假设当前状态只依赖前一状态，假设特征独立，计算速度快但效果有限。CRF（条件随机场）是判别式模型，直接对给定观测序列下的隐藏状态序列的条件概率建模，不做特征独立假设，效果更好。线性链 CRF 是序列标注（NER、词性标注）的经典方法，在 BERT 之前是 state-of-the-art。

## 和我的项目的关系

HMM/CRF 是序列标注的经典方法，虽然现在被大模型取代了，但 CRF 的「全局归一化」思想仍然有启发：CRF 考虑整个标签序列的联合概率而不是每个位置独立，这和我做 KG 质量评估时考虑整个图谱的一致性而不是每条三元组独立是同一个思路。[[TripleChecker]] 里可以借鉴这个想法，把多条相关三元组的验证联合起来做，而不是每条独立判断——比如如果「阿里巴巴 → 创始人 → 马云」和「马云 → 创立 → 淘宝」都对，那「阿里巴巴 → 旗下 → 淘宝」正确的概率就更高。
